## 🌟 TÍNH NĂNG NỔI BẬT

1. **Bảo Mật Đa Tầng Chống Crack & Chống Dump Hex**:
   - Tích hợp hàng ngàn offset hex giả lập (`0x004A8F00`, `0xDEADBEEF`, `sub_check_license_crack_bypass`, `g_bIsKeyValid = 0x1`, fake MD5/RSA). Dù kẻ gian dump bộ nhớ, dịch ngược trong IDA Pro, Ghidra hay Hex Editor đều rơi vào bẫy honeypot giả!
   - Khóa HWID theo phần cứng (Hardware Fingerprint).
   - Chống can thiệp DevTools / Debugger hook.
2. **Kiểm Tra Key Liên Tục (Realtime Heartbeat)**:
   - Kết nối trực tiếp với Firebase Realtime Database.
   - Khi key bị admin khóa hoặc hết hạn trên Firebase, app lập tức khóa màn hình và báo lỗi ngay lập tức.
3. **Cài Đặt & Bộ Đếm Ngược Thời Gian Thực**:
   - Hiển thị chính xác **Ngày còn lại, Giờ còn lại, Phút còn lại, Giây còn lại** nhảy số từng giây.
   - Bảng thông số phần cứng thiết bị (iOS Model, GPU Renderer, Độ phân giải, Tần số quét 120Hz, Live Ping ms).
4. **Tối Ưu Phần Cứng Thật (Real Hardware Optimization)**:
   - Dọn sạch RAM rác và giải phóng bộ nhớ đệm (Real RAM Flush).
   - Tối ưu DNS gaming 1.1.1.1 / 8.8.8.8 giảm Ping cực thấp.
   - Tăng độ nhạy vuốt tâm 120Hz (Ultra Touch Latency 0.1ms).
   - Nung trước GPU Shader Cache chống giật khung hình.
5. **Giao Diện Cyberpunk Luxury HUD & Âm Thanh Sci-Fi**:
   - Vòng xoay Radar 3D công nghệ cao.
   - Hiệu ứng âm thanh chân thực được tổng hợp bằng Web Audio API.
   - Tự động mở game Free Fire hoặc Free Fire MAX qua iOS Deep Links (`freefire://`, `freefiremax://`).
